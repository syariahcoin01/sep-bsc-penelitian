# Strategic Educational Planning and Balanced Scorecard Implementation (Studi Kasus: Pada Satuan Pendidikan Dasar Menengah) – Website Penelitian v2

**Peneliti:** Dr. R. A. E. Virgana Targa Sapanji, S.Kom., M.T.
**Afiliasi:** Program Studi Sistem Informasi, Universitas Widyatama

Progressive Web App (PWA) yang menyajikan laporan penelitian Strategic Educational Planning (SEP) dan Balanced Scorecard (BSC) untuk satuan pendidikan dasar dan menengah.

## Fitur

- **Laporan lengkap** Bab 1–5 beserta lampiran
- **Galeri visual** gambar, diagram, dan infografis penelitian
- **Studio interaktif**:
  - Strategy Map
  - AHP (Analytic Hierarchy Process)
  - Delphi–CVR (Content Validity Ratio)
  - Scorecard
  - Cascading
  - Cek RKAS/BOSP
  - SWOT–TOWS
  - SUS (System Usability Scale)
- **Research Planner 16 langkah** mengikuti alur DSRM (Design Science Research Methodology)
- **Tombol batalkan / ulangi / reset** pada alat interaktif
- **Keterangan singkatan** (daftar akronim yang dipakai di seluruh situs)
- **PWA offline**: dapat dipasang dan dibuka tanpa koneksi internet setelah kunjungan pertama

> **Catatan:** Angka-angka pada sekolah kasus bersifat **ilustratif** dan tidak merepresentasikan data resmi satuan pendidikan tertentu.

## Menjalankan secara lokal

```bash
python3 -m http.server 8000
```

Lalu buka <http://localhost:8000> di peramban.
